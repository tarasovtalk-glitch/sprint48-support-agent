# SMF — ИИ-агент поддержки Softline Store

Конкурсная задача №6 хакатона «ИИКузница». Агент помогает клиентам магазина подобрать лицензии, отвечает на вопросы о заказах и счетах, готовит КП и передаёт сложные обращения оператору со сводкой.

Веб-чат Softline работает на Webim. Интеграция через API «Умный бот 2.0» предусмотрена для пилота. Конкурсное демо использует отдельный стенд и данные, разрешённые организаторами для демонстрации.

Предстартовый стенд: [analyzebot.ru/support/](https://analyzebot.ru/support/).
