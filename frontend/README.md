# Интерфейс агента поддержки Softline Store

Две страницы для стенда `https://analyzebot.ru/support/`:

| Адрес | Что это |
|---|---|
| `/support/` | Копия главной store.softline.ru с окном чата Webim. В окне отвечает ИИ-помощник |
| `/support/cabinet/` | Кабинет менеджера: «Сегодня» (решения), «Журнал», «Знания», «Агент» (статистика, лимит, настройки) |

Без фреймворков и зависимостей: HTML, CSS и JS. Все пути относительные, поэтому страницы работают под `/support/` без настройки.

## Сборка

```bash
cd frontend
npm ci
npm run build
```

Результат в `frontend/dist/`. Эту папку целиком отдаём по адресу `/support/` (nginx: `alias /…/frontend/dist/;`).

Переменные сборки:
- `API_BASE`: адрес API агента, по умолчанию `/support/api`.
- `DEMO=1`: всё работает на примере данных, без сервера.

Сборка пишет их в `dist/config.js`. Этот файл можно поправить прямо на сервере, без пересборки.

## API

Контракт в корневом [README](../README.md), раздел «API для фронтенда». Экраны чата и кабинета не знают адресов сервера: их запросы переводит `src/api.js`.

| Что на экране | Запрос к серверу |
|---|---|
| Клиент открыл чат | `POST /sessions`, токен разговора хранится во вкладке |
| Клиент написал или нажал кнопку-ответ | `POST /case/messages`, канал всегда `chat`. Кнопки «Узнать цену», «Получить КП», «Выставить счёт», «Нужна отсрочка» уходят как `action` |
| Файл КП или счёта в чате | `document_url` из ответа, ссылка живёт 15 минут |
| Решение менеджера появилось в чате | `GET /case` раз в 3 секунды, сообщение при смене состояния |
| Кабинет, «Ждут решения» | `GET /manager/cases` |
| «Согласовать» и «Отказать» | `POST /manager/cases/{id}/decision` с `version` и `request_id`. Повтор после обрыва идёт с тем же `request_id`. На 409 кабинет просит обновить страницу |
| «Как шёл разговор» | `GET /manager/cases/{id}/journal` |

Журнал, справка, статистика и настройки агента в API пока не входят: эти вкладки показывают пример и пишут об этом строкой сверху. Истории сообщений у сервера нет, поэтому переписку для восстановления после перезагрузки страницы чат держит во вкладке.

### Ключи

В исходниках и в сборке ключей нет.
- `X-Demo-Key` подставляет веб-сервер перед API. На стенде это nginx:
  ```nginx
  location /support/api/ {
      proxy_pass http://127.0.0.1:8000;
      proxy_set_header X-Demo-Key $support_demo_key;   # значение из закрытого файла конфигурации
  }
  ```
- Ключ менеджера кабинет спрашивает один раз полем и держит до закрытия вкладки (`sessionStorage`).

## Локальная проверка

```bash
# сервер агента из корня репозитория
SUPPORT_DATABASE=./local.sqlite3 SUPPORT_DEMO_KEY=… SUPPORT_MANAGER_KEY=… uvicorn support_app.app:deployment_app --factory --port 8000
# интерфейс
cd frontend
SUPPORT_DEMO_KEY=… npm start      # http://localhost:8080/support/ и /support/cabinet/
npm run preview                    # то же из dist
node scripts/serve.mjs --no-api    # без сервера: как интерфейс выглядит, если API не отвечает
```

`scripts/serve.mjs` отдаёт страницы и передаёт `/support/api` на сервер агента (`SUPPORT_API`, по умолчанию `http://127.0.0.1:8000`), подставляя `X-Demo-Key` так же, как nginx.

Режимы без сервера: `/support/?demo` (сценарий чата без сервера), `/support/#offhours`, `/support/#now` (чат как сейчас, меню и менеджер), `/support/cabinet/?demo`.

## Копия сайта

Копия сайта сделана только для демонстрации: ссылки никуда не ведут, страница закрыта от поисковиков (`noindex`), внизу слева стоит пометка «Демо-стенд хакатона, не магазин».
