# Интерфейс агента поддержки Softline Store

Две страницы для стенда `https://analyzebot.ru/support/`:

| Адрес | Что это |
|---|---|
| `/support/` | Копия главной store.softline.ru с окном чата Webim. В окне отвечает ИИ-помощник |
| `/support/cabinet/` | Кабинет менеджера: «Сегодня» (решения), «Журнал», «Знания», «Агент» (статистика, лимит, настройки) |

Без фреймворков и зависимостей: HTML, CSS и JS. Все пути относительные, поэтому страницы работают под `/support/` без настройки.

## Сборка

```bash
cd frontend
npm ci
npm run build
```

Результат в `frontend/dist/`. Эту папку целиком отдаём по адресу `/support/` (nginx: `alias /…/frontend/dist/;`).

Переменные сборки:
- `API_BASE`: адрес API агента, по умолчанию `/support/api`.
- `DEMO=1`: всё работает на примере данных, без сервера.

Сборка пишет их в `dist/config.js`. Этот файл можно поправить прямо на сервере, без пересборки.

## API

Контракт в [API.md](API.md). Для цепочки «чат → агент → менеджер → ответ в чат» нужны `/chat/...` и `/cases...`. Остальные разделы кабинета без сервера показывают пример и пишут об этом.

Ключей во фронте нет и не будет: модель, почту и заявки вызывает только сервер. Браузер ходит только на `API_BASE` того же сайта.

## Локальная проверка

```bash
npm start              # http://localhost:8080/support/ и /support/cabinet/, с заглушкой API
npm run preview        # то же из dist/
node scripts/serve.mjs --no-mock   # без API: как интерфейс выглядит, если сервер не отвечает
```

Заглушка `scripts/mock-api.mjs` отвечает по ключевым словам («отсрочка», «скидка», «счёт», «macOS», «менеджер») и держит данные в памяти. Это не агент.

Режимы без сервера: `/support/?demo` (сценарий чата от 24.11), `/support/#offhours`, `/support/#now` (чат как сейчас, меню и менеджер), `/support/cabinet/?demo`.
